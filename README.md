# Reporte de Incidencias

Herramienta HTML autocontenida: pega el texto de una incidencia y genera una constancia lista para imprimir o guardar en PDF.

## Uso

1. Abrir `reporte.html` en el navegador.
2. Pegar el texto de la incidencia en el area de texto.
3. Clic en **Cargar Datos al Reporte**.
4. Clic en **Guardar en PDF / Imprimir**.

## Stack

Un solo archivo. Sin servidor, sin build, sin dependencias, sin llamadas de red.
